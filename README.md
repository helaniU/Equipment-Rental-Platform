# Equipment Rental Management Platform

Full-stack engineering assessment for Apps Global a platform for renting
professional equipment (camera gear, tools, drones, construction equipment).

## Tech stack
- Backend: NestJS, PostgreSQL, TypeORM, Redis/BullMQ
- Frontend: Next.js, React, TypeScript
- Mobile: Flutter
- Auth: JWT + Role-Based Access Control (Admin, Staff, Customer, Warehouse Operator)
- Storage: AWS S3 / Cloudflare R2

## Project structure
- `/backend` - REST API
- `/frontend` - Admin/staff web dashboard
- `/mobile` - Customer & staff Flutter app
- `/docs` - ER diagram, API docs, deployment instructions

## Getting started
See `backend/README.md`, `frontend/README.md`, `mobile/README.md` for
